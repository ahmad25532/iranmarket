# 🤖 Iran Market AI | دستیار هوشمند تحلیل و سرمایه‌گذاری بورس، طلا و نقره ایران

سامانه جامع و هوشمند تحلیل بازار سرمایه ایران، طلا، نقره و رصد ریسک‌های کلان و ژئوپلیتیک با رابط کاربری فارسی (RTL) و اتصال مستقیم دوگانه‌سوز (Dual-Route) به سرورهای بورس ایران (بدون نیاز به خاموش کردن VPN) و خبرگزاری‌های بین‌المللی.

## ✨ امکانات کلیدی

1. **⚡ خلاصه فرمان روز هوش مصنوعی:**
   - اعلام صریح سیگنال‌های **خرید پله‌ای**، **فروش / سیو سود / پرهیز** و **استراتژی پارک نقدینگی در ریال امن (صندوق‌های درآمد ثابت ~۳۰٪)**.
2. **👑 کالبدشکافی ۳ جانبه طلا، دلار آزاد و انس جهانی:**
   - دریافت تاریخچه ۳۰ روزه دلار، طلای ۱۸ عیار، سکه و انس جهانی از `TGJU`.
   - محاسبه خودکار حباب ذاتی طلا و سکه، دلار مستتر در طلا، `RSI(14)`، فاصله از میانگین متحرک ۲۰ روزه و **نوار احتمال صعود در برابر اصلاح طلا**.
3. **💼 مدیریت پرتفوی شخصی و دستیار هشدار خروج:**
   - ثبت نمادهای موجود در سبد شما به همراه قیمت خرید و دریافت فرمان لحظه‌ای **«نگهداری قوی»**، **«نگهداری»** یا **«هشدار خروج / سیو سود»** بر اساس فرار پول هوشمند یا اشباع خرید (`RSI`).
4. **♟️ ماتریس ۵ کانون ژئوپلیتیک و کلان:**
   - رصد زنده رسانه‌های تراز اول بین‌المللی (`Reuters`, `WSJ`, `CNBC`, `Bloomberg`, `BBC`, `Al Jazeera`) در ۵ محور:
     - 🇮🇱 انتخابات و کابینه اسرائیل
     - 🇺🇸 انتخابات میان‌دوره‌ای و کاخ سفید آمریکا
     - 🇶🇦 میانجی‌گری قطر/عمان و پرونده آتش‌بس
     - 🛢️ امنیت انرژی، نفت و تنگه هرمز
     - 🏦 تورم داخلی و سیاست بانک مرکزی
5. **🏭 رادار هوشمند صنایع و راست‌آزمایی تحلیل‌ها:**
   - رتبه‌بندی زنده صنایع (استخراج طلا و نقره، دارو، سیمان، پتروشیمی، پالایشی، بانکی، خودرویی و...) بر اساس ورود پول حقیقی و کالبدشکافی تک‌تک نمادها و اطلاعیه‌های کدال هر صنعت.
6. **🪙🥈🚀 دیده‌بان جامع صندوق‌ها (ETFs):**
   - صندوق‌های طلا (`عیار`، `طلا`، `کهربا`، `گوهر`، `مثقال` و...)
   - صندوق‌های نقره (`سیمین`، `سیلور`، `نقرابی`، `نقران` و...)
   - صندوق‌های اهرمی (`اهرم`، `موج`، `بیدار`، `توان`، `دوایکس` و...)
   - صندوق‌های خاص زعفران (`سافرون`، `نهال`) و املاک و مستغلات (`کلید`، `ارزش مسکن` و...)
   - صندوق‌های درآمد ثابت (`لبخند`، `افران`، `یاقوت`، `کمند` و...)
7. **💎 شکارچی سهام و کالبدشکافی فوری نماد:**
   - غربالگری کل بازار بورس و فرابورس بر اساس ترکیب **تابلوخوانی (قدرت خریدار و ورود پول حقیقی)** + **ارزش‌گذاری (`P/E`)** + **تکنیکال (`RSI` و حجم مشکوک)** + **آخرین گزارش‌های سایت کدال (`codal.ir`)**.

## 🗄️ لایه داده (فاز ۱)

داده‌ها در `data/market.duckdb` ذخیره می‌شوند (قیمت خام روزانه، جریان پول حقیقی/حقوقی، NAV صندوق‌ها، شاخص‌ها، دلار/طلا/سکه/انس).
بعد از هر اجرا، بررسی کیفیت داده انجام و نتیجه در جدول `quality_checks` ثبت می‌شود.

| فایل | کار |
|---|---|
| `net.py` | اتصال HTTP با گواهی TLS معتبر و مسیر مستقیم برای سایت‌های داخلی |
| `sources.py` | دریافت و تبدیل داده‌های TSETMC، TGJU و Fipiran (تاریخچه NAV) |
| `datastore.py` | ساختار پایگاه داده DuckDB |
| `quality.py` | بررسی‌های کیفیت داده |
| `collector.py` | اجرای روزانه و دریافت تاریخچه |

نصب (یک بار):

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

دستورها:

```bash
.venv\Scripts\python.exe collector.py backfill   # تاریخچه کامل (یک بار، حدود ۱۰ تا ۲۰ دقیقه)
.venv\Scripts\python.exe collector.py daily      # عکس روزانه + جبران روزهای از دست رفته (هر وقت و هر چند بار)
.venv\Scripts\python.exe collector.py status     # وضعیت داده‌ها و پوشش ۱۰ روز معاملاتی اخیر
.venv\Scripts\python.exe -m pytest -q tests      # تست‌ها
```

### اجرای خودکار و جبران روزهای خاموش بودن کامپیوتر

تسک «IranMarketAI Daily Collect» در Task Scheduler ویندوز فایل [`run_daily_collect.bat`](run_daily_collect.bat) را اجرا می‌کند:
- ساعت ۱۶:۰۰ شنبه تا چهارشنبه، ساعت ۲۰:۰۰ هر روز، و ۵ دقیقه بعد از هر بار ورود به ویندوز
- اگر کامپیوتر سر ساعت خاموش باشد، اولین فرصت بعد از روشن شدن اجرا می‌شود

`daily` هر بار اجرا شود:
1. اگر عکس پایانی امروز هنوز گرفته نشده، می‌گیرد (عکس قبل از ساعت ۱۴ نهایی حساب نمی‌شود و دوباره گرفته می‌شود).
2. روزهای معاملاتی ۱۲۰ روز اخیر را با تقویم شاخص کل مقایسه می‌کند و هر روزی که ناقص است (مثلاً به دلیل سفر) را از تاریخچه رسمی پر می‌کند: قیمت و جریان پول از TSETMC، NAV صندوق‌ها از Fipiran.
3. اگر همه چیز کامل باشد، در کمتر از یک دقیقه تمام می‌شود.

گزارش هر روز در `data/logs` ذخیره می‌شود.

محدودیت‌های شناخته‌شده:
- Fipiran بعضی NAVها را یکی دو روز دیرتر منتشر می‌کند؛ سیستم تا کامل شدن آن روزها دوباره تلاش می‌کند.
- اگر کامپیوتر بیش از ۱۲۰ روز روشن نشود، باید یک بار `backfill --refresh` اجرا شود.
- فقط نمادهای فعلی بازار دریافت می‌شوند و نمادهای حذف‌شده نیستند (سوگیری بقا در بک‌تست).
- در عکس روزانه، ارزش ریالی جریان حقیقی/حقوقی خالی است (فقط حجم و تعداد)؛ روزهایی که از تاریخچه پر می‌شوند ارزش دقیق دارند.
